# Lebwohl-Lasher
An implementatiuon of the Lebwohl-Lasher problem in Python to investigate the effect of a number of accelerated code principles 

To run the subsequant version of each piece of code, navigate to the correct file and write:

```Py
python -m LebwohlLasher_{method} ITTER SIZE TEMP PLOTFLAG
```
To run the mpi implementaion:

```Py
mpirun -np <np> LebwohlLasher_mpi ITTER SIZE TEMP PLOTFLAG
```
